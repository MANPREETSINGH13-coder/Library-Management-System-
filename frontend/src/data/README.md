# Registration dropdown data

- Academic options: BBAU programme catalogue, https://www.bbau.ac.in/Courses.aspx?pn=1 through pn=6. Retrieved 2026-10-25. These are registration choices, not an admissions eligibility guide.
- Indian states and districts: https://github.com/CodingMation/indian-states-districts/blob/main/data/india_states_districts.json (MIT; license included). Retrieved 2026-10-25.
- Lists are bundled locally so registration does not depend on external requests. Refresh the datasets when departments, courses or district boundaries change. Other / not listed options allow registration where a published list is incomplete.
